# Meolaa brand assets

Official files for the React app. Source: Downloads brand kit + user-provided wordmarks.

## Logo

| File | Content | Use on |
|------|---------|--------|
| `logo.png` / `logo-dark.png` | Black / dark wordmark | Light / ecru |
| `logo-white.png` | Ecru/cream wordmark | Planet Blue / dark |
| `logo.svg` | Vector from Downloads | Prefer when coloring via CSS/fill |

Guidelines: use **Planet Blue** logo wherever possible; always keep contrast. Min digital height **8px**. Clearspace ≈ height of letter “M”. Don’t stretch, tilt, recolor outside brand colours, or restyle the E-arrow.
